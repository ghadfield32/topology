# One continuing foundation: the 31 core stages and sports bridges

The original lessons, primers, proofs, notebooks and assignments remain in place.
These are topic-specific application prompts, not 31 newly executed independent
sports benchmarks. The seven S sections contain the new executed work. Tasks
requiring full video, independent geometry truth or labels are explicitly plans.

Use the existing stage's beginner entry page first. Then attempt its bridge.
Never skip a prerequisite because a model API happens to return an array.

## A route that does not overwhelm a beginner

First pass: core 00–03, sports S00–S01, one retained tabular industry lab.
Second pass: core 04–10, sports S03–S04, one image or climate example.
Third pass: core 11–12, sports S05–S06, an independent protocol.
Geometry continuation: core 13–20 when the selected question needs camera frames,
spatial reconstruction or event timing. Physics continuation: core 21–30 when
the question genuinely needs differential equations or learned dynamics. S02
can start with algebra and return to the deeper dynamics later.

Efficiency means skipping redundant reading after demonstrated understanding,
not skipping counterexamples, hand calculation or independent evaluation. Revisit
a difficult proof with the retained free textbook references. No observer is
expected to master every advanced branch from one introductory package.
