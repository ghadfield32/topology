# Release 2.0 — build on, do not replace, the first course

## Preserved

The original 13 lessons, 102 conceptual exercises and worked answers, 13 real-data labs, fixed datasets/splits, mathematical conventions and honest scope boundaries remain. No claim of having read the actual book was added. Known demonstration test labels stay known; they are not presented as a fresh holdout.

## Added

Four beginner primers; 13 deeper stage workbooks; 65 coding tasks (five per stage) with learner starters, hints, checks and separate reference solutions; 13 executed reference-answer notebooks; 39 delayed-retrieval questions with answer criteria; a proof atlas; stage hubs; a local evidence-backed learning log and CLI; a small own-CSV explorer; coverage and continued-study guides; and an updated offline reader. These are original instructional additions, not excerpts from the book or the free reference texts.

## Verification boundaries

Worked notebooks are executed. Learner notebooks intentionally contain assignments and are not counted as passed work. Tests are arranged so completing learner code does not break the package's core suite. Software tests, self-reported learning evidence, independent assessments, statistical validation, and actual-book coverage are different claims.

The v1 verification report is retained under `reports/archive_v1/` as history. Current evidence is in `docs/VERIFICATION.md` and `reports/v2_release.json`. External-library checks remain explicitly unverified when Ripser/GUDHI cannot be installed; no skipped check is relabeled passed. The v2 log does not silently import or synchronize v1 browser progress.
