- Preserve the 13-stage topology course and all 65 practice activities. Append stages 13–20 as an applied extension, not as claimed book chapters.

- Add a single version-3 progress log with explicit migration from v2 and no manufactured achievements. Migration never overwrites v2.
- Track source disagreements openly: Omega project page and repository display different September update dates. Preserve the attached source account; annotate the independently checked difference.
