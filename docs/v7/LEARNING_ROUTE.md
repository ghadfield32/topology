## Case selection without overload

For an unfamiliar table, begin with Seeds or Wine. For uncertainty and units, use Concrete Slump. For repeated-unit evaluation, use the new leakage lab and retained transportation case. For chronological reasoning, use CO2 or the marine series. For actual camera geometry, use the stereo case rather than forcing a scalar table into a reconstruction problem. For mechanics and PDE learning, use the labeled manufactured controls before designing an independent physical-data study.

## Meaningful stopping points

Complete stages 00–12 for the defined introductory topology/TDA route. Continue through 13–20 for the spatial-evidence extension and 21–30 for introductory scientific ML. Each track still requires its independent assessments. The source audit and depth map state which advanced proofs and domain validations are beyond these demonstrations.
