# Your first session: do this before studying holes

1. Open `START_HERE.html` after extracting the ZIP completely. Choose **Stage 00**. Read its lesson through the explanation of observations, features and labels. Use the Python primer whenever a code expression is unfamiliar; you are not expected to infer notation from context.
2. Read the first worked table in the Stage 00 workbook. On paper, explain what a single row represents, count the numeric measurement columns, and distinguish a species label from a measurement.
3. Open the saved Stage 00 lab in the reader. Predict the shape of a 150-row, four-measurement array before revealing or running its output. Predict the shape of one 8×8 image and the number of scalar entries.
4. Install the Python environment only when ready to rerun. The read-only lessons and saved results do not require installation. In Jupyter open `notebooks/00_lab.ipynb`, restart the kernel, and run from the first cell. Record one output in your own words, not just a screenshot.
5. Open `practice/learner/00_practice.ipynb`. Complete **00.C1** first. Its starter deliberately raises `NotImplementedError`. Replace that line with your implementation and run its check cell. A red starter is an assignment, not a broken completed course.
6. Complete the remaining four coding exercises and the six conceptual exercises when comfortable. Hints are allowed during practice; declare that help rather than treating it as independent assessment.
7. Create `my_work/00_answers.md` and record your answers, what you changed in the lab, and what you still cannot explain. Run the CLI practice record using that real file. Do not mark the course complete because the reference solution passes.

**First-session success:** you can explain the data shapes, the distinction between an observation and a label, and why a software check is different from a claim about the world. No understanding of homology is required yet.

After an independent stage assessment, use a later date for delayed recall. The log will not count same-day repetition as seven-day retention. Stage 01 is ready when you can navigate the notebook and explain the basic data objects, not when you can recite every mathematical word in the glossary.
