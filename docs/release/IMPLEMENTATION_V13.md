# v13 design: learning sessions and portable experiment evidence

Continue the existing course without another required theory track. Preserve every primary lesson,
practice route, source distinction, historical failure record, data license, and learner file.

Implement an explicit beginner session composed from the canonical stage/case registry, a prediction
sheet, a private learner notebook, and a reflection form. Do not mark a learner as assessed. Implement
local result export only from a newly sealed, successful reference run. Hash the actual executed
notebooks and generated artifacts; detect later changes and unsafe paths; render code and outputs
without executing stored JavaScript. A report is a reproducible teaching-result draft, not a claim of
external validation or public publication.

Harden Docker verification so command return codes alone cannot establish runtime acceptance: validate
child test/reference evidence, exact scope, and output-file continuity. Docker/Kubernetes remain blocked
when tools or a daemon are unavailable. Never fabricate a resolver lock or equate inherited packages
with a fresh installation. Native, container, cluster, source truth, and mastery are distinct gates.

Preserve the original package under its own filename. Build in an isolated extracted folder. Do not
modify a remote repository, install into the user's computer, create clusters, or publish any report.
