# Coverage, depth and what is still a separate project

This is a complete combined teaching package for the declared paths, not a claim to exhaust topology, mathematics, computer vision or scientific machine learning. All topics in the four new attachments have an explicit destination. "Included" does not mean "paper benchmark reproduced."

## Three paths, one foundation

| Path | Stages | Completion evidence |
|---|---|---|
| Shape and persistence | 00–12 | Definitions, hand calculations, proofs, tested algorithms, real-data interpretation and an independent capstone |
| Geometry and spatial evidence | 13–20 | Coordinate/frame checks, stereo references, data contracts, independent geometry evaluation and timing |
| Dynamics and scientific learning | 21–30 | Explicit assumptions, derivatives, numerical invariants/counterexamples, small trained models, observed-data discipline and a new independent study |

A new learner begins at 00. A continuing learner uses recorded evidence, not assumed ability, to resume. The original book scope ends before much of the applied continuation; the additional branches are our extensions.

## What “100% of the agreed course” should mean

All required learning outcomes have independent evidence, critical misconceptions have been corrected, reference work can be reproduced, and delayed recall still succeeds. Watching a video, running a solved notebook or opening an answer does not establish those outcomes.

The proposed 24-week estimate in the original foundation plan applies to that core, not to every extension. Use demonstrated understanding instead of promising that a fixed number of hours will exhaust these subjects. Add the physics branch after its prerequisites; do not postpone all learning until every optional research branch is implemented.

## Gap obligations stay visible

Read the actual book when available and audit its sections against completed work. For a paper reproduction, obtain the original code and data under their licenses, record commit/checkpoint/configuration, reproduce its baseline and metric, then explain deviations. For empirical physics, acquire independent measured trajectories/fields and a valid observation model. For deployment, test actual sensors, precision, runtime, failure recovery and monitoring. None of those statuses is automatically green in the supplied log.
