Learn any lab in Python, Go or Rust

One notebook triad per learning unit: the same lab, the same registered inputs, the same comparison — three languages. Start with Python, then Go, then Rust. See the guide and the import record.

Each notebook is unassessed. Nothing here is a second mandatory curriculum.

Find your way around (the folders have different jobs)

This trips people up, because several folders hold Go or Rust code:

| Path | What it is | Do you edit it? | |---|---|---| | workbooks/polyglot/python/ | notebooks that run the canonical Python reference | no | | workbooks/polyglot/go/ | notebooks that run the real Go program | no | | workbooks/polyglot/rust/ | notebooks that run the real Rust program | no | | native/go/, native/rust/ | the reference source those notebooks compile | no — read-only reference | | my_work/<session>/native/go|rust/ | your copy from native_course.py prepare | yes — here | | notebooks/, lessons/, practice/ | the original course labs and assignments | your learner notebook |

notebooks/ is the original course. It has no go or rust folder, and it is not where these notebooks live. There are 57 notebooks per language (171 in total) under workbooks/polyglot/.
