Stage 07 transfer guide — Filtration scale is not chronological time

Original stage learning section · Worked case · Dataset card

Start at the right level

This guide extends From data to shape: Rips, Čech, alpha, and filtrations; it does not replace the stage's definitions, proofs, exact controls or exercises. Read the beginner data primer whenever the distinction between a row, feature, group or fitted parameter is unclear. The inherited stage includes the appropriate runnable core lab.

Connect the concept carefully

A Rips threshold in standardized chemistry space is a distance. A CO2 window has a chronological time index. Both may index constructions, but they do not mean the same thing. An alpha filtration may use squared-radius values rather than the edge threshold used by this course.

Your guided experiment

Write down the Rips membership rule before reading a diagram. On the unit square, determine exactly when edges and triangles enter. Record scale convention and maximum simplex dimension in the experiment record.

Before running code, write a concrete prediction. After running, record the actual input rows, transforms and output. When using a manufactured control, label it as such. When using observed measurements, preserve units and metadata limitations from the data card.

Check understanding, not only execution

Explain Rips versus Cech using pairwise distances versus a common ball intersection. Do not compare raw alpha coordinates to edge thresholds without converting conventions.

Evidence and continuation
