Stage 02 transfer guide — A distance depends on scale

Original stage learning section · Worked case · Dataset card

Start at the right level

This guide extends Closeness, metrics, neighborhoods, and topologies; it does not replace the stage's definitions, proofs, exact controls or exercises. Read the beginner data primer whenever the distinction between a row, feature, group or fitted parameter is unclear. The inherited stage includes the appropriate runnable core lab.

Connect the concept carefully

Use two wine measurements and calculate Euclidean distance by hand in two selected coordinates. Now multiply just one coordinate by 1000. This imitates a unit change, not a new physical sample. The raw distance changes. Standardizing with frozen training statistics creates another declared metric, not the uniquely correct metric.

Your guided experiment

Compare three nearest reference rows before and after an intentional feature rescaling using only the training set. Use the original metric lesson to check triangle inequality on an exact control rather than infer a theorem from numerical examples.

Before running code, write a concrete prediction. After running, record the actual input rows, transforms and output. When using a manufactured control, label it as such. When using observed measurements, preserve units and metadata limitations from the data card.

Check understanding, not only execution

Identify the chosen features, units or unknown units, fitted scale and reference rows. A label code must not be included as a numerical measurement.

Evidence and continuation

Save my_work/stage_02_transfer.md with your prediction, hand calculation, executed notebook path, explanation and one non-supported conclusion.
