Execution environment

Python 3.13.5, Linux CPU. Tested libraries: NumPy 2.3.5, SciPy 1.17.0, pandas 2.2.3, scikit-learn 1.8.0, matplotlib 3.10.8, PyTorch 2.10.0+cpu. Exact environment and per-notebook timings are in the JSON records. These timings describe the build environment, not a promised runtime on another machine.

Ripser and GUDHI were not installed. Their comparisons are explicitly skipped, not passed. No Mac, Windows or GPU execution is claimed. No trained VGGT inference, independent sports-event evaluation, full-paper benchmark reproduction or production-system modification was performed in this addition.

Browser checks

Chromium rendering, 41 searchable stage/industry links, 36 new question/recall cards, answer reveal, the exact square-filtration explorer, an embedded concrete-interval figure, deliberate learner-stub labels, and 390-pixel layouts were checked. No JavaScript page errors were recorded.

Direct file navigation was blocked by the environment with ERR_BLOCKED_BY_ADMINISTRATOR. The automated renderer therefore checked source-injected pages and interactions rather than claiming successful local home-to-stage navigation. File-link targets are checked separately. Fragment-anchor semantics and all external links were not exhaustively audited. No remote font or script asset is required by the new reader, and no font files are shipped.

New observed-data experiments

Seeds: 126/42/42 fixed stratified split. The seven-feature classifier gets 38/42 test labels correct; without the compactness feature it gets 39/42; the majority baseline gets 14/42. No test tuning was performed in the declared protocol. Descriptive persistence uses 24 specified training rows in standardized feature space, not physical grain holes. This new lab does not claim a predictive benefit from TDA.

Concrete Slump: 52 fitting rows, 25 calibration rows, 26 test rows. Fixed ridge MAE is 2.20324 MPa; the training-mean baseline MAE is 6.14050 MPa. At nominal 90% marginal coverage, the corrected calibration rank is 24, radius 5.34000 MPa and width 10.67999 MPa. The fixed intervals cover 25/26 observed test outcomes. Missing batch/time identities mean exchangeability and future-batch coverage are not established; this is not structural safety certification.

Leakage stress test: three exact software copies per observed Seeds row produce 630 constructed rows but still 210 observed kernels. The row-split test shares 131 source units with training and gets 189/189 copied rows correct. The group-split test shares no source units and gets 180/189 rows correct. This is an illustrative manufactured leakage mechanism, not an estimate of optimism in every real dataset.

Claims/evidence: the symplectic oscillator map passes its matrix condition while energy changes .5 to .4808 in the worked step. One nonlinear sphere correction leaves residual .5625. Opposite gradients have no strictly common first-order descent direction. These are original exact controls, not reproduced climate, HPC or PINN-paper benchmark results.

Each real-data case retains its source record, split, protocol, predictions, metrics and fitted model parameters. Regression tests reconstruct predictions from saved scaling and coefficients and compare them with the retained outputs.

Acquisition and source limitations

All numeric records of the two new UCI datasets were transcribed from complete official web-retrieved plaintext because direct container downloads failed. Whitespace and field names were normalized; a source ID was added for Seeds. No values or rows were intentionally changed. Shapes, finite values, class counts and selected endpoints were checked; those checks cannot rule out every transcription error.

Local SHA-256 and canonical numeric fingerprints verify the delivered representation, not an independently obtained provider checksum. The opt-in remote numeric verifier is included but was not run in this build. Undocumented source units, acquisition dates and batch identities remain explicitly unknown. The earlier 13 observed sources retain their historical acquisition records; their labs were rerun, not all sources independently re-acquired.

Corrections found during this build

A generated byte-string newline was corrected in the Stage 20 entry script. A high-precision decimal test exposed rounding in canonicalization; exact decimal formatting replaced it. The full suite caught notebook-only magic syntax incompatible with inherited plain-Python compile checks, and a stale release version. Both source generation and release identity were corrected; the checks were not weakened. The final reference notebooks were rerun afterward. Detailed logs and the inline self-review are retained. This was not a separate-agent or independent mathematical peer review.

Artifact integrity and final extraction

The root MANIFEST.sha256 covers delivered files except itself. Previous release manifests are preserved under explicitly historical names. The accompanying external Listening_to_Shape_v7_Final_Archive_Check.json records ZIP integrity, fresh extraction, imported source path, fresh-copy test outcome and post-test hash checks. Those checks are performed after the archive is created; do not infer them from source-folder tests alone.

The complete book audit, deeper theorem-proof obligations and independent domain-specific capstones remain open learning tasks. Software tests do not automatically mark a learner competent. The core and industry work logs ship empty and must not overwrite a user's existing attempts.
