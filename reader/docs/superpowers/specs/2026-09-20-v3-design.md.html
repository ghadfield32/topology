Version 3: topology first, measured geometry next

User intent

Extend the supplied v2 learning system, not replace it. Begin with no mathematical prerequisites, retain detailed staged explanations and real-data labs, and add a carefully sourced bridge to VGGT, manifolds, camera geometry, performance, and interaction evidence. Preserve learner work. Deliver an entire offline-readable ZIP with inspectable code and honest execution status.

Decisions

  • Preserve the 13-stage topology course and all 65 practice activities. Append stages 13–20 as an applied extension, not as claimed book chapters.
  • Use locally available scikit-image Middlebury stereo motorcycle data for a measured, offline geometry thread. Retain upstream attribution and calibration. Do not label reconstructed reference disparities as independent 3D measurements or a held-out model benchmark.
  • Implement small CPU mathematical baselines. No GPU, model weights, or external installs are required by the core lessons.
  • Supply an opt-in original-VGGT adapter with local checkpoint, exact repository revision, explicit license review, model provenance, and schema checks. GPU inference is not claimed unless actually executed.
  • Keep static reconstruction, dynamic inference, metric validation, and topological descriptors distinct. Refuse to turn proximity, confidence, or a visually plausible cloud into certified contact, calibration, or physical accuracy.
  • Add a single version-3 progress log with explicit migration from v2 and no manufactured achievements. Migration never overwrites v2.
  • Track source disagreements openly: Omega project page and repository display different September update dates. Preserve the attached source account; annotate the independently checked difference.

Components

shape_lab.geometry: charts, SO(3), SE(3), projection, DLT, similarity registration. shape_lab.stereo: data loading, calibration, disparity-to-depth, SAD baseline and error measures. shape_lab.attention: educational stable attention and frame/global masking. shape_lab.temporal: timing, causal proximity hypotheses, event matching, and explicit missing-data semantics. shape_lab.learning: backward-compatible progress migration. notebooks/13..20_lab.ipynb: fully worked executed demonstrations. lessons, workbooks, solutions, practice: matched stage teaching and independent assessment. optional/run_vggt_local.py: opt-in adapter, never automatically run or download weights.

Scope and evidence

No copyrighted book text is reproduced. No production WMS mutation, model training, actual phone calibration, clinical analysis, or basketball-event benchmark is claimed. Source claims, derived math, controlled simulations, reference-data checks, and measured runtime each receive a separate label. Executed reference solutions are not student assessments.
