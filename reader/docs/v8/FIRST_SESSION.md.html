Troubleshooting

A learner NotImplementedError is an assignment: implement that function first. An import error usually means the wrong environment or working folder: check python -c "import sys; print(sys.executable)" and rerun the editable install. A hash mismatch means inspect changes, not delete the check. An unavailable value in a gap is expected evidence withholding. A failed network request does not mean the dataset is empty. A skipped Ripser/GUDHI test is not a passed comparison.
