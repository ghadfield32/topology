Source audit and limits — v8

What is retained from the user's supplied material

The original teaching sequence remains intuition, precise definition, hand calculation, code, test and interpretation. The earlier source posts discuss PINN gradient conflicts, Hamiltonian versus Lagrangian learning, symplectic structure/projection, smooth charts, VGGT, timing and human-object interactions. Their terminology and the prior source-attributed claim audits remain in the existing course. v8 does not replace those posts with assertions that a sports model has reproduced them. The new sports calculations are original teaching experiments, not new results from those authors.

The prior posts' exact-energy and one-step nonlinear-projection claims retain their documented counterexamples. No new climate, petascale GPU or professional sports validation is claimed. New dataset and licensing information below comes from current primary-source research, not the attached posts.

Current primary-source research

The sports registry was checked on 2026-09-21. It includes 2026 releases and 2025 resources that match different tasks. It is not an exhaustive ranking of all current datasets, and a recent documentation change does not imply newly collected observations.

SPL distinguishes the March 2026 documentation update from a 2025-12-18 session. SkillCorner's inspected records are 2024/25 season summaries; the current README also exposes tracking and body-pose resources, with distinct sampling, missingness and coordinate limitations. BasketHAR's April 2026 paper, MUVS's June 2026 record and UVY's July 2026 record describe different modalities. OpenBiomechanics's current README documents a July 2026 history rewrite and release-based large files. The catalogue records all of these as source statements, not reproduced benchmarks.

New data acquisition: explicit limitation

Container network downloads failed, but official text was accessible through web and GitHub read tools. Two small numeric excerpts were transcribed from those outputs. No synthetic records substitute for those excerpts. No whole original sports dataset was downloaded. The 12 selected SPL frames and first 12 SkillCorner profile rows preserve the selected fields' displayed numerical values, with metadata and omissions documented in their cards.

The full original Git blob SHA1 is recorded for each source and local SHA256 for each excerpt. Those local hashes prove only local identity. They cannot establish that a manual transcription is error-free. The optional verifier checks original file revision, source metadata, selected row IDs and numeric values. Its parsing and mismatch behavior were tested on constructed fixtures; the remote full-source comparison was not executed successfully here.

Full data and model access not performed

Full SkillCorner tracks/body pose, BasketHAR signals/video, MUVS videos/sensors, UVY video, TrackID3x3 media, SoccerTrack v2, SoccerNet video, OpenBiomechanics data, and BASKET-Multiview render payloads are not bundled or executed. The SkillCorner XY adapter is explicitly schema-tested on constructed rows. It is not an executed full-match model. VGGT inference and the older optional Ripser/GUDHI comparisons remain outside this build's successful executions.

Rights are artifact-specific

SPL data and derived excerpts are CC BY-NC-SA 4.0; keep the attribution and share- alike/noncommercial conditions. SkillCorner's repository MIT notice is copied. TrackID3x3's current README distinguishes CC BY 4.0 data, Apache original code, and a noncommercial third-party jersey component. OpenBiomechanics distinguishes MIT code from restricted data/documentation. Some rendered repository records do not expose enough license information; the catalogue says so instead of guessing. No course code license licenses unrelated videos, weights or commercial products.

Interpretation boundaries tested or taught

A hash is not geometry validation. Frames are not independent athletes. Feature clouds are not pitch locations. Interpolation is not newly measured data. A past- only source-time function does not by itself account for real arrival latency. A small fit residual does not identify gravity, release time or camera calibration. A stable descriptor need not be useful. A supervised sports benchmark needs more independent data than these deliberately small teaching excerpts.

See the individual cards and SPORTS_DATASETS.md for primary URLs, dates, units, access conditions, baselines, split plans and specific failure modes. The actual book text remains unaudited; its chapter-by-chapter checklist is retained.
