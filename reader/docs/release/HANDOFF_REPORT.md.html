What this round changed

  1. --check was a silent no-op. The plan's Phase B command tools/build_language_notebooks.py --check previously ignored the unknown flag, rewrote all 171 workbooks, and exited 0. There is now a real checker: it renders the expected tree in memory (a single render() source of truth), compares it, and exits 1 naming every missing, stale or unexpected artifact. Proven able to fail: editing README.md by hand returns 1; restoring it returns 0. Unknown flags are now a hard error.
  2. Fresh vs review execution modes. The Python notebook's evidence cell now has MODE = "fresh" (default) or MODE = "review", with PINNED_RUN required in review mode. Fresh mode creates the evidence by compiling and running the native labs into the notebook's own directory — verified by executing Stage 01, which produced a new run whose identity was recorded. Review mode opens a specific run and labels it as previous execution. Neither scans for "the newest plausible folder".
  3. Learner mutation is now a full cycle. The test proves the private copy is what gets evaluated (via go list -f {{.Dir}}), then fail → repair → pass: the XOR→OR edit fails TestRankField, and restoring the source makes it pass again. Both languages verified.
  4. An inaccurate aliasing claim was corrected. My earlier note called the Go append a "row-aliasing" case. It is not one: clone deep-copies each row (b[i] = append([]float64(nil), a[i]...)), so x cannot be reached. The walkthrough now says so explicitly and turns the correct fact into the exercise (delete clone and observe the difference).
