Deliberately not imported (deferred, not rejected)

The archive is a v13/v14 base wrapped around native16. The following were held back because they are a coordinated version change, not additive learning material, and the repository's uv.lock is a genuine, resolved lock tied to the current package version:

  • src/shape_lab/result_packet.py, study_session.py and the v13 edits to acceptance.py, cli.py, course.py, deployment.py (course.py study / report commands), with tests/test_results_v13.py, tests/test_deployment_receipts_v13.py and docs/release/RESULTS_WORKFLOW.md.
  • Package version bump 12.0.0 → 14.0.0 in pyproject.toml and src/shape_lab/__init__.py.
  • v12 → v13/v14 relabels in curriculum/catalog.json, curriculum/START.md, RELEASE_MANIFEST.json, README.md, AGENTS.md, root docs, the CI workflow (image:12 → 13) and deploy/kubernetes/resources.json (namespace shape-learning-v12 → v13).

Relabelling without bumping pyproject.toml/__init__.py and regenerating uv.lock together would have made tests/test_release_version_v3.py fail; the archive's own migration doc lists that reconciliation as optional step 5/6. A coordinated v14 reconciliation is a separate, reviewable change.

notebooks/00_lab.ipynb, 01_lab.ipynb and 02_lab.ipynb have genuine source edits in the working tree. Those are local learner work and were preserved, not reverted to the archive copies.

The 130 other notebook differences in the archive are saved-output refreshes only; comparing stripped notebook source confirmed the teaching cells are identical, so nothing was overwritten.
