v5 design and execution record

Goal: preserve the full v4 course and add a beginner-first scientific-machine-learning track (21–30) motivated by four supplied posts. The requested deliverable is the combined ZIP, not only a plan.

The teaching spine is definitions → hand calculation → executable experiment → independent exercise → limits → delayed recall. Existing topology and camera-geometry stages remain canonical. New stages have explicit prerequisites, observation provenance, and source-claim distinctions. No assumption of a physics background. No production WMS changes, paid resources, or automatic model downloads.

Components: inspectable NumPy mathematics in shape_lab.physics; optional PyTorch CPU training examples; ten lessons and paired worked/practice notebooks; source audit; concept coverage map; compatible 31-stage evidence log; v5 offline reader linking preserved v4 pages. New neural examples are manufactured benchmarks, not replications of cited papers. Real observations are used only for claims they support.

Verification: establish v4 baseline; write failing tests before mathematical implementations; analytic counterexamples and invariant tests; actual notebook execution; full regression suite; HTML target checks; independent archive extraction and hashing. Report optional-library skips, platform limits, and unexecuted literature reproductions.

Task sequence:

  1. Mathematical core, data provenance and counterexample tests.
  2. Small trained neural models and reference experiments.
  3. Stage lessons, exercises, answers, topic/source audit.
  4. Compatible progress migration and reading interface.
  5. Execute and package; report evidence rather than inferred completeness.
