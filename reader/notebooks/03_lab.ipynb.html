Predict forward and inverse continuity separately.

Code · execution 3

from shape_lab.topology import powerset, is_continuous
X = {0, 1}; discrete = powerset(X); indiscrete = [set(), X]; identity = {0: 0, 1: 1}
forward = is_continuous(X, discrete, X, indiscrete, identity)
reverse = is_continuous(X, indiscrete, X, discrete, identity)
print("Identity discrete→indiscrete:", forward, "Reverse:", reverse)
assert forward and not reverse

Real-data transformations

We prove ambient continuity algebraically in the lesson; these finite numerical checks illustrate it and compare distance behavior.

Code · execution 4

from shape_lab.data import load_iris_data
from scipy.spatial.distance import pdist
X = load_iris_data().iloc[:, 1:5].to_numpy()
D = pdist(X); translated = pdist(X + np.array([2., 3., 4., 5.]))
rescaled = pdist(X * np.array([1., 2., 1., 1.]))
projected = pdist(X[:, :2])
assert np.allclose(D, translated)
assert np.all(projected <= D + 1e-12)
print("Translation max distance error:", np.max(abs(D-translated)))
print("Rescaling max distance change:", np.max(abs(D-rescaled)))
plt.figure(figsize=(6, 4)); plt.scatter(D, projected, s=5)
plt.xlabel("Full four-feature Euclidean distance (cm)")
plt.ylabel("Projected two-feature distance (cm)")
plt.title("Projection can discard separation in real Iris data")
show_and_save(OUT / "projection_distance_loss.png")
save_json(OUT / "results.json", {"finite_forward_continuous": forward, "inverse_continuous": reverse,
          "translation_error": np.max(abs(D-translated)), "rescaling_change": np.max(abs(D-rescaled))})

Explain the limit

A projection can happen to be injective on finitely many sample points while not being injective on the ambient space. Do not confuse the two claims.
