1. From measured stereo pixels to directions

The reference disparity and calibration produce camera-frame points. Normalizing each nonzero point gives a viewing direction on a unit sphere. This is a representation of directions: it is not a claim that the motorcycle scene is spherical. The source pixel IDs remain attached.

2. Two charts for the same direction

The south-pole chart is safe for these forward-looking rays. The north-pole chart becomes badly conditioned near the forward axis. Both are exact coordinate descriptions away from the excluded poles; neither adds depth.

Code · execution 4

3. A tangent vector is not a new point on the sphere

Differentiate the inverse chart numerically. Its two columns must lie in the tangent plane at the reconstructed direction. Then compare a first-order approximation against the nonlinear map as the step shrinks.

Code · execution 5

a = south[len(south)//3]
fun = lambda z: sphere_unchart(np.asarray(z)[None,:], "south")[0]
J = finite_jacobian(fun, a)
q = a@a
J_analytic = np.vstack([2*np.eye(2)/(1+q)-4*np.outer(a,a)/(1+q)**2, -4*a/(1+q)**2])
assert np.allclose(J, J_analytic, atol=1e-8, rtol=1e-7)
print("Analytic/finite-difference Jacobian agreement:", np.max(np.abs(J-J_analytic)))
p = fun(a)
tangency_error = float(np.max(np.abs(p @ J)))
assert tangency_error < 1e-7
v = np.array([0.4, -0.2]); steps = np.array([0.1,0.05,0.025,0.0125])
errors = np.array([np.linalg.norm(fun(a+h*v)-(p+h*(J@v))) for h in steps])
print("Tangency residual:", tangency_error, "linearization errors:", errors)
assert np.all(np.diff(errors) < 0)
plt.figure(figsize=(6,4)); plt.loglog(steps,errors,marker="o")
plt.xlabel("Step size"); plt.ylabel("Linearization error"); plt.title("A local linear model becomes more accurate locally")
show_and_save(OUT / "tangent_linearization.png")
