1. Real image patches, deliberately simple features

We use real left/right image crops as inputs. Flattened patches and their standardized intensities are the toy tokens; no learned backbone, positional embeddings, training, camera head, depth head or track head is present. This is not VGGT inference.

from shape_lab.attention import patch_tokens,attention,frame_mask
cropL=left[180:244,300:364].mean(axis=2)/255.
cropR=right[180:244,300:364].mean(axis=2)/255.
TL,rcL=patch_tokens(cropL,8);TR,rcR=patch_tokens(cropR,8)
T=np.vstack([TL,TR]);frame_ids=np.repeat([0,1],[len(TL),len(TR)])
T=(T-T.mean(axis=1,keepdims=True))/(T.std(axis=1,keepdims=True)+1e-8)
print("Tokens:",T.shape,"per image:",len(TL),len(TR))
within,Wframe=attention(T,T,T,mask=frame_mask(frame_ids))
combined,Wglobal=attention(within,within,within)
assert np.allclose(Wframe.sum(1),1) and np.allclose(Wglobal.sum(1),1)
assert np.all(Wframe[frame_ids[:,None]!=frame_ids[None,:]]==0)
print("Within-frame then global token output:",combined.shape)
plt.figure(figsize=(6,5));plt.imshow(Wframe);plt.colorbar(label="Row-normalized weight")
plt.xlabel("Key patch index");plt.ylabel("Query patch index");plt.title("Toy within-frame attention — block mask")
show_and_save(OUT / "frame_attention.png")

2. A token can now depend on another frame

Change the second frame while preserving the first. The first frame-only output must stay unchanged, while its subsequent global output can change. That verifies information flow, not geometric understanding.

3. Read the optional inference contract before running a model

optional/run_vggt_local.py is a separate opt-in runner. It needs an existing official repository checkout, its exact revision, a locally stored checkpoint and explicit license acknowledgement. It does not auto-download weights. Its coordinate frame and scale remain predictions until independently registered and checked.

The original model's track output has two image coordinates per query per frame. A validated metric 3D trajectory would additionally require appropriate depth/triangulation, time alignment, coordinate registration and visibility/uncertainty checks. Industry use cases in the supplied post are hypotheses, not benchmark results.
