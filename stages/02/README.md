## This stage's gate

Verify metrics and topology axioms, prove finite discreteness, and distinguish observed points from inferred shape.

Use [the assessment rubric](../../docs/LEARNING_SYSTEM_V2.md); a passing software test is only one component. Record a real evidence file in [your work folder](../../docs/release/YOUR_WORK.md), then log a practice, assessment, or delayed-recall attempt. All learner records start unassessed.
