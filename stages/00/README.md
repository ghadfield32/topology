# Stage 00 — Start here: how to learn, run, and question the results

**Prerequisite:** No topology, proof-writing, or Python background is assumed.

## Learn, then do

| Step | Resource | Evidence to produce |
|---|---|---|
| 1. Build intuition | [Core lesson](../../lessons/00_lesson.md) | Explain the main idea with an example and a nonexample. |
| 2. Slow down the hard parts | [Beginner workbook](../../workbooks/00_workbook.md) | Work its calculation and distinguish the objects being compared. |
| 3. Repair a prerequisite | [Foundation primer](../../foundations/00_numbers_symbols_and_types.md) | Translate unfamiliar notation or code into ordinary language. |
| 4. Predict and experiment | [Executed real-data lab](../../notebooks/00_lab.ipynb) | Predict, run, modify one condition, and explain the result. |
| 5. Write it yourself | [Five coding activities](../../practice/learner/00_practice.ipynb) | Replace the deliberate starters and pass their specified checks. |
| 6. Check after attempting | [Coding solutions](../../practice/00_solutions.md) · [Executed answers](../../practice/answers/00_practice.ipynb) | Identify differences in reasoning, not only output. |
| 7. Reason independently | Conceptual exercises at the end of the lesson; [solutions](../../solutions/00_solutions.md) | Submit your own explanation or proof before looking. |
| 8. Recall later | [Delayed questions 00.R1–R3](../../practice/retrieval.md) | Work with notes closed and explain a changed example. |

## This stage's gate

Run Stage 00, explain its data shapes and provenance, and distinguish code execution from understanding.

Use [the assessment rubric](../../docs/LEARNING_SYSTEM_V2.md); a passing software test is only one component. Record a real evidence file in [your work folder](../../docs/release/YOUR_WORK.md), then log a practice, assessment, or delayed-recall attempt. All learner records start unassessed.
