## Connect the concept carefully

A regional scalar SST record can create many windows but not independent solution fields with different initial conditions. The optional Well catalogue is a different data role: numerical simulations. It is not bundled or empirically evaluated in this release.

## Your guided experiment

Reproduce the small manufactured DeepONet/FNO heat examples. Then design a split by entire simulated trajectory/condition, not neighboring frames, and distinguish it from the observed SST chronological split.

Before running code, write a concrete prediction. After running, record the actual input rows, transforms and output. When using a manufactured control, label it as such. When using observed measurements, preserve units and metadata limitations from the data card.

## Check understanding, not only execution

State input function, output function, domain, discretization, units, solver provenance and independent split. Do not call a window classifier an operator benchmark.
