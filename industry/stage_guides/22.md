## Connect the concept carefully

The local diffeomorphism material uses assumptions about smooth vector fields and existence intervals. A trained next-value regression on a scalar series need not be invertible or define such a flow. Seasonal forcing and missing state also matter.

## Your guided experiment

Work the exact forward/inverse flow and finite-time blow-up controls in Stage 22. Compare their contracts with the one-step CO2 model, specifying which premises are not supplied by observations.

Before running code, write a concrete prediction. After running, record the actual input rows, transforms and output. When using a manufactured control, label it as such. When using observed measurements, preserve units and metadata limitations from the data card.

## Check understanding, not only execution

Keep existence, uniqueness, invertibility and numerical reversibility separate. A learned map is not a diffeomorphism merely because it has an attention layer or low prediction error.
