## Connect the concept carefully

Multiplying all distances by two scales barcode coordinates. Arbitrary changes in metric or reference selection are a different experiment, not an application of a fixed-filtration perturbation theorem. A long interval may still reflect a sampling artifact or a design choice.

## Your guided experiment

Perturb a training-only fixed cloud by a declared bounded coordinate error, preserve point identities, and record the resulting diagrams. State which stability theorem could apply and its hypotheses before comparing numbers.

Before running code, write a concrete prediction. After running, record the actual input rows, transforms and output. When using a manufactured control, label it as such. When using observed measurements, preserve units and metadata limitations from the data card.

## Check understanding, not only execution

Do not apply a sublevel-function sup-norm bound to an unrelated preprocessing change. Explain deterministic robustness separately from statistical significance and usefulness.
