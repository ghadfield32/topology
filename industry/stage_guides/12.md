## Connect the concept carefully

Transfer the topology-course evaluation discipline to an unfamiliar industry. The transport example makes observation-unit errors visible: four stored rows can belong to a single decision. A good report needs more than a model score.

## Your guided experiment

Write an experiment contract before running the transport notebook: question, information set, grouping, split, transforms, baseline, metrics, assumptions, limits. Then compare it to the executable protocol and saved predictions.

Before running code, write a concrete prediction. After running, record the actual input rows, transforms and output. When using a manufactured control, label it as such. When using observed measurements, preserve units and metadata limitations from the data card.

## Check understanding, not only execution

The report is reproducible and the claim matches the unit and split. An actual-book audit remains open until the text itself is checked.
