## Connect the concept carefully

A PINN needs a specified equation, boundary/initial conditions, coordinates and unit scales. None is supplied merely by a table having temperature and flow columns. The original Poisson PINN is a known-answer manufactured experiment; the plant case is observed regression.

## Your guided experiment

Compare the analytic Poisson reference, finite-difference baseline and trained PINN in Stage 26. Then write the additional measurements and governing assumptions required before making the plant experiment physics-informed.

Before running code, write a concrete prediction. After running, record the actual input rows, transforms and output. When using a manufactured control, label it as such. When using observed measurements, preserve units and metadata limitations from the data card.

## Check understanding, not only execution

A low PDE residual does not establish the right PDE for the real system, and a small fit error cannot replace parameter identifiability or independent boundary validation.
