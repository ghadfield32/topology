## Connect the concept carefully

A choice label is available after a traveler selects a mode. A release label in sports may need future frames for offline confirmation. Using these outcomes as live inputs would be leakage. The transport case turns this abstract rule into visible excluded columns.

## Your guided experiment

List the earliest availability of each transport feature; identify psize as tied to the chosen mode in the source description. Separately distinguish onset time and confirmation time in the inherited event lab.

Before running code, write a concrete prediction. After running, record the actual input rows, transforms and output. When using a manufactured control, label it as such. When using observed measurements, preserve units and metadata limitations from the data card.

## Check understanding, not only execution

A predicted proximity event is not verified contact, and a choice classifier does not prove a price intervention effect. Report what was observed versus inferred.
