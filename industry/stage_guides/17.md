## Connect the concept carefully

Registering geometry and standardizing feature space are different operations, but both have a fit/evaluate boundary. A transformation fitted to an evaluation target can make performance look artificially good. Wine reference rows make that boundary visible in a small setting.

## Your guided experiment

Check that anchor rows and supervised fitting rows are disjoint. Then revisit similarity registration in Stage 17 and use separate fit and evaluation points. Explain why a scale gauge must be fixed before metre-valued errors make sense.

Before running code, write a concrete prediction. After running, record the actual input rows, transforms and output. When using a manufactured control, label it as such. When using observed measurements, preserve units and metadata limitations from the data card.

## Check understanding, not only execution

No test reference is used to fit its own transformation. Predicted shape, registered shape and independently measured shape remain distinct.
