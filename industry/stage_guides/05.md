## Connect the concept carefully

The WDBC table contains measurements extracted from images; it does not contain the pixels needed to construct a cell-image cubical complex. Use the inherited handwritten-digit lab for actual pixel geometry. Use the WDBC table only as a point cloud after a metric is chosen.

## Your guided experiment

Build an unfilled triangular boundary and a filled triangle by listing their simplices. Explain why the extra face changes the complex even though the visible vertices and edges can look similar. Identify which actual data source supplies pixels in the original course.

Before running code, write a concrete prediction. After running, record the actual input rows, transforms and output. When using a manufactured control, label it as such. When using observed measurements, preserve units and metadata limitations from the data card.

## Check understanding, not only execution

Never manufacture a 2-D image by reshaping thirty unordered features and call its holes cell morphology. State the data-to-complex rule and face closure.
