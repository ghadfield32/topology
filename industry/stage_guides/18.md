## Connect the concept carefully

Optimizing a data conversion can change array layout or drop rows. A faster notebook is not an improvement if weekly time gaps become invisible. Throughput and end-to-end latency are also different quantities.

## Your guided experiment

Profile a vectorized calculation and a simple loop on identical finite inputs. Assert equal outputs, preserve original indices and missingness, and report the boundary being timed. Compare with the inherited queue-age experiment.

Before running code, write a concrete prediction. After running, record the actual input rows, transforms and output. When using a manufactured control, label it as such. When using observed measurements, preserve units and metadata limitations from the data card.

## Check understanding, not only execution

Report measured CPU timings as CPU timings, not GPU throughput or full live-system latency. Explain how batching can improve throughput while worsening result age.
