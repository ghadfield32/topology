# Stage 20 beginner workbook

## Reproduce before transferring
Run the final evidence-summary lab after the earlier bridge labs. Inspect which numbers come from measured real-image comparisons, imposed transformations, generated timing traces, and unexecuted integrations. Every row should answer “what exactly was tested?”

## Design your own question
Write a one-page protocol using the template in `docs/INDEPENDENT_SPATIAL_CAPSTONE_V3.md`. State a falsifiable improvement criterion and at least one plausible failure condition. Freeze final-evaluation choices before looking at its outcome. A negative result is a completed experiment if the protocol and evidence are sound.

## Independent defence
Explain the metric, projection convention, calibration references, registration split, confidence semantics and missing-data treatment without reading your code. Then show the code that implements each choice. A mismatch between the explanation and the implementation is a gap to resolve, not a presentation issue.

## Keep the handoff small
The progress handoff should record your current stage, evidence paths, unresolved misconceptions and next specific exercise. Preserve raw notebooks and measurements; summarize them rather than copying every output into the next chat. No automatic mastery claims are generated from a successful test run.

## Three passes

**Understand:** work the hand example and identify an assumption. **Build:** run the worked lab, predict a change, and implement the coding exercises. **Demonstrate:** answer unfamiliar questions without the solutions and return for delayed recall. Passing reference code does not assess your understanding.
