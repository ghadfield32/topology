# Coverage: actual implementation, not blanket certification

Every row below has substantive native Go and Rust code. All 57 have been compiled and run in the delivery environment; per-run evidence is separate. These are the new shared **native16** protocols. They are not advertised as complete operation-for-operation ports of all 133 Python notebooks. Nothing in this table marks learner mastery.

## Remaining full-equivalence work

General native alpha/Delaunay construction; every original model architecture/optimizer/validation search; the complete original descriptor choices; original-source graphical renderers; pretrained VGGT inference; full PointNet/semantic-scene pipelines; all external toolkit APIs; complete independent capstones; and live deployment of these NEW native images remain outside the certified work. The full Python course and the Poux source map remain available rather than being replaced by smaller exercises.

A requirements checker must not report full-original parity solely because all native16 runs pass. `native_course.py verify --require-original-parity` refuses that unsupported claim.

## Dataset scope

The registry covers all 55 files under the canonical bundled data directories, including terms/metadata and preserved derivative inputs. It does not call 55 files 55 datasets. Full-value comparison includes repeated image arrays represented in PNG and NPZ; the number of values compared is not a sample-size claim. Optional large source corpora, weights and external credentials are not supplied. Native readers are bounded to 256 MiB per source/expanded archive rather than promising arbitrary-scale streaming.
